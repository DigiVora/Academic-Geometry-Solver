# Academic-Geometry-Solver
Academic Geometry Solver adalah aplikasi kalkulator geometri berbasis Java Swing. Aplikasi ini dirancang untuk menghitung luas dan keliling bangun datar (Jajar Genjang, Lingkaran, Persegi, Persegi Panjang, Segitiga, Trapesium) secara otomatis. Menawarkan antarmuka yang bersih, responsif, dan error handling untuk pengalaman belajar yang optimal.
